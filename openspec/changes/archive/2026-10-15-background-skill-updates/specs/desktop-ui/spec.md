# Spec Delta

## ADDED Requirements

### Requirement: 更新管理弹窗可关闭且更新继续

更新管理弹窗 MUST 在检查、更新与历史操作期间支持关闭按钮、Esc 和外部点击关闭。关闭或离开设置页 MUST NOT 中断已开始的更新；重新打开 MUST 反映全局更新状态及持久化历史。

#### Scenario: 更新期间关闭并重新打开
- **WHEN** 更新尚未结束，用户通过任一关闭入口关闭弹窗并重新打开
- **THEN** 更新继续执行，弹窗仍显示更新进行中并阻止重复更新

#### Scenario: 离开设置页后更新完成
- **WHEN** 用户离开设置页且后台更新完成后返回更新管理
- **THEN** 更新状态恢复空闲，列表和历史从当前数据读取

### Requirement: 后台批量更新结果通知

应用 MUST 为每次批量或所选更新的最终结果显示一次本地化通知，无论设置页是否挂载。通知 MUST 区分成功、部分失败、全部失败和无需更新，失败时提供可读原因；命令拒绝 MUST 只显示一次错误通知。

#### Scenario: 后台完成
- **WHEN** 用户已关闭更新管理或离开设置页，更新结束
- **THEN** 通知概括更新结果，部分或全部失败时给出成功与失败数量并带有原因

#### Scenario: 重复缓存事件
- **WHEN** 同一次更新结算后缓存发生其他通知或监听组件重新挂载
- **THEN** 不再次提示旧结果

#### Scenario: 没有需要更新的技能
- **WHEN** 更新完成且成功与失败数量均为零
- **THEN** 显示无需更新的提示而非失败

### Requirement: 并发写操作冲突友好报错

安装、单个更新、全部或所选更新、删除命令遭遇已占用写操作租约时 MUST 返回稳定错误码 `operationInProgress`。界面 MUST 显示当前语言的稍后重试提示，不展示原始租约报错。其他租约建立失败 MUST 保留原错误分类，不伪装成并发操作。

#### Scenario: 更新时删除或安装
- **WHEN** 更新占用写操作租约，用户删除或安装技能
- **THEN** 命令立即失败，显示友好的稍后重试提示，已有更新继续

### Requirement: 后台更新退出确认

真实退出入口在批量或所选更新命令存活时 MUST 要求确认，取消 MUST 保留窗口与任务，重复退出请求 MUST NOT 堆叠确认。窗口关闭与托盘退出 MUST 覆盖；macOS 系统 Cmd+Q 与 Dock 退出受当前原生框架限制，不保证确认。没有后台更新时 MUST 保留既有退出行为。

#### Scenario: 更新中关闭窗口或托盘退出
- **WHEN** 用户在后台更新期间关闭主窗口或选择托盘退出
- **THEN** 显示本地化退出确认，取消后窗口与更新仍存活，确认后退出

#### Scenario: 未更新或任务结束
- **WHEN** 没有后台批量更新，用户请求退出
- **THEN** 无更新确认，按既有行为退出
